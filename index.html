客户端

只说明用途和配置思路，本页不提供安装包下载地址。

桌面端

Windows / macOS

适合固定工位长期在线。装好后按订阅信息填入配置，桌面端一般会常驻托盘或菜单栏，方便随时切换线路。多设备名额里，一台电脑算一台。

移动端

iOS / Android

手机和平板各算一台设备。移动端更适合临时使用，长时间挂着会额外耗电。iOS 上通常需要通过系统级配置导入，具体以客户端说明为准。

路由与扩展

路由器 / 浏览器扩展

路由器方式能让整个局域网共用一份配置，适合家里设备多的情况；浏览器扩展只作用于浏览器流量，不接管系统其他应用。两者都计入设备名额。

常见问题

按被问到的频率分组。有答案，不敷衍。

关于套餐与价格

年付真的比月付便宜吗？便宜多少？

是的。年付按 10 个月计价：基础版 ¥150 / 年、旗舰版 ¥350 / 年、团队版 ¥850 / 年，相当于两个月不收费。

没有额外的折扣码，也不用凑单。年付一次付清，中途不按比例退。

我这个月流量没用完，能留到下个月吗？

不能。流量按自然月结算，当月未用完的部分不结转。所以选档的时候别一味往大了挑，按实际用量来更划算。

中途想换档位，怎么处理？

可以升档，也可以降档，但档位变更从下一个计费周期生效，当前周期内的流量和设备上限不随之变动。

如果只是想临时多挂一台设备，不建议为此升档，退出另一台设备的登录更快。

关于设备与使用

设备数是怎么算的？换手机要重新占名额吗？

算的是同时在线的数量，不是注册绑定。旧设备退出登录后，名额立刻释放，新设备可以直接用。

所以换手机不用额外付费，也不需要联系客服解绑。

三个档位在流媒体上的区别具体在哪？

基础版是基础流媒体解锁；旗舰版和团队版是全节点原生解锁，覆盖的平台范围更宽。团队版在此之上提供 VIP 专属高带宽节点。

具体某个平台能不能看，取决于该平台当下的策略，这里不做逐个平台的保证。

我用路由器方式，会占用好几台设备名额吗？

会占，但通常只按一份配置计。路由器后面的手机、电脑共用这一份，不会逐台叠加。

具体以你所用客户端在设备侧的识别方式为准，如果出现异常占用，可通过工单反馈。

关于支持与变更

出问题找谁？不同档位的支持有差别吗？

统一走工单。旗舰版提供 7×24 优先工单支持，团队版另有专属客户经理。基础版同样可以提单，只是排在普通队列。

提单时把客户端类型、系统版本和现象写清楚，处理会快不少。

团队版的“企业定制路由”需要额外谈吗？

属于团队版权益范围内，由专属客户经理对接具体需求。能定制到什么程度要看你的网络结构，本页不预先承诺方案细节。
